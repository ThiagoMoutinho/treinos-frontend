## Tarefa

Crie um chatbot que chame a rota `/ai` da API (não use o Orval).

## Requisitos técnicos

- Use Vercel AI SDK.
    ```tsx
    const { messages, sendMessage, status } = useChat({
        transport: new DefaultChatTransport({
        api: '/api/chat',
        }),
    });
    ```
- Armazene o estado da abertura do chat na URL e também armazene uma mensagem inicial que será enviado a chat automaticamente. Use a biblioteca do "nuqs" para fazer isso. Exemplo:
localhost:3000?chat_open=true&chat_initial_message=message
- Abra o chatbot ao clicar no botão central da barra de navegação (ocom icone Sparkles).
- Abra o chatbot ao clicar no botão "?" do "exercise-card.tsx e a messagem inicial (passada via URL) deve ser "Como executar o exercicio X corretamente?"
- Use a biblioteca "streamdown" para formatar a mensagem do chatbot
- Ao abrir o chatbot e não haver nenhuma mensagem, exiba a mensagem sugeridas: "Monte o meu plano de treino"
